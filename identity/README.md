# Identity Layer

`AXEL.md` is the recovered text of Paseo's `daemon.appendSystemPrompt` from
the current Windows configuration. It is the canonical portable copy of Axel's
global identity prompt.

The repository-root `AGENTS.md` is the canonical operating-rules file copied
from the current OpenCode configuration. A runtime that supports both should
load both, with workspace-level `AGENTS.md` files remaining more specific.

`personality.md`, `operating-principles.md`, and `workflows.md` are derived maps
for humans and runtime adapters. They consolidate existing language from
`AXEL.md`, `AGENTS.md`, installed skills, and the curated memory notes. They do
not add a second personality or override the canonical files.
