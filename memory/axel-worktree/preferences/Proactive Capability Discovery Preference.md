# Proactive Capability Discovery Preference

The agent should proactively notice useful tools, services, open-source projects, and agent capabilities while working, including sources beyond GitHub. It should investigate promising candidates without interrupting for minor decisions, then report what it found, likely benefit, costs, permissions, maintenance burden, and risks. The user decides whether to proceed. The agent must not silently install tools, add credentials, create external accounts, or make persistent configuration changes. Read-only research and small disposable experiments are allowed when safe, and must be distinguished from persistent changes.
