# OpenCode Plugins

The global `%USERPROFILE%\.config\opencode\plugins` directory is empty. The
active CodeMem plugin is sourced from the local CodeMem checkout and is stored
under `tools/integrations/codemem/`. The experimental Axel local-memory plugin
is stored under `tools/integrations/opencode-local-memory/` and must remain
disabled until its documented disposable-profile gate passes.
