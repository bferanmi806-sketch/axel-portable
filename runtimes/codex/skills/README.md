# Codex Skills

- `installed/` contains the non-system Codex skill directories copied from the current installation.
- `memories/` contains three Codex-specific reusable skills for Baymax/Graphify/session-integrity/Dreamer work.

The Codex system skill bundle, plugin caches, and generated memory/session data
are not included. Skills that overlap with OpenCode's global skill collection
are preserved in both runtime locations where the current installations had
separate copies.
