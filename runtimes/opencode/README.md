# OpenCode Runtime

OpenCode is the preferred independent runtime adapter in this package. Load
the repository-root `AGENTS.md`, `identity/AXEL.md`, the relevant skills and
the Basic Memory project. Materialize `opencode/config/opencode.json.template`
with the local checkout path before launching.

The observed Windows OpenCode CLI was `1.18.18`. The WSL Ubuntu configuration
was minimal and did not contain Axel instructions; it is recorded in the
inventory and is not used as the source of truth.
