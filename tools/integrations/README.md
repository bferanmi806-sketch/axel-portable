# Integrations

- `codemem/` is the current local CodeMem source snapshot, excluding its Git metadata, dependencies, generated build output and databases.
- `axel-improvement-engine/` is the local-first, model-agnostic trajectory and compounding engine used by the `/compound` command.
- `opencode-local-memory/` is an experimental, safe-off OpenCode adapter. It is preserved for future review but must not be enabled in the live global config.
- `last30days.env.example` records optional provider variable names without values.
